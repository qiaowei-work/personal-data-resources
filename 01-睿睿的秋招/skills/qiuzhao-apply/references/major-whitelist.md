## 白名单（命中任一即纳入候选）

**必须用穷举白名单，不要用模糊匹配。** 招聘平台给的是学科**类目名**（"化学工程与技术类"），简历写的是专业名（"化学工程与技术"），差一个"类"字就对不上。漏一个类目 = 漏掉一批岗位。

### 核心（化工直接对口）

- 化学工程与技术类
- 化学类
- 化工与制药类
- 材料与化工类

### 材料

- 材料科学与工程类
- 材料类

### 相关

- 环境科学与工程类
- 安全科学与工程类 / 安全类
- 能源动力类
- 冶金工程类
- 环境保护类
- 有色金属材料类

### 不限专业

- 工学全类
- 理学全类

## 对口分（用于异地排序）

数字越小越对口。同一岗位命中多个类目时取**最小值**。

| 分 | 类目 | 说明 |
|-|-|-|
| 0 | 化学工程与技术类 | 硕士专业精确命中 |
| 1 | 化学类 | |
| 2 | 化工与制药类 | 本科专业所在类目 |
| 3 | 材料与化工类 |（注意：`材料与化工` 在部分站点是专业学位类别，易与 `材料与化工类` 混淆）|
| 4 | 材料科学与工程类 | |
| 5 | 材料类 | 泛化，命中率高但区分度低 |
| 6 | 环境科学与工程类 | |
| 7 | 安全科学与工程类 / 安全类 | |
| 8 | 能源动力类 | |
| 9 | 冶金工程类 | |
| 10 | 环境保护类 | |
| 11 | 工学全类 | 不限专业 |
| 12 | 理学全类 | 不限专业 |

字段未命中时，从 JD 正文中按上表顺序找第一个出现的类目，取该分。

## 重要限制：对口分 ≠ 适配度

**专业类目命中只说明"能投"，不代表岗位合适。**

实测反例：
- 「初级循环再生工程师」专业列材料类，实际是工程项目管理（招标/施工进度/档案）
- 大量「采购岗/供应链岗」专业要求写"材料类"——因为采购材料的人需要材料专业，但那是职能岗不是研发岗

**所以对口分只用于排序，不能用于定档。定档必须读 JD 正文。**

## 排序后果提示

按对口分排序会系统性偏向"专业名称精确匹配"的岗位，可能把职责更相关的岗位挤出榜单。

实测：中铝案例中「新兴材料研究员」（北京，招 3 人，职责就是材料研发，专业列"化学类"= 对口分 1）被三个对口分 0 但各只招 1~5 人的岗位挤出 Top3。

排完后应检查一次：被挤出的是否有职责明显更相关的？如有，向用户说明这个取舍。
